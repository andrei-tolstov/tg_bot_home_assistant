# 🏠 Telegram Bot для Home Assistant

Легковесный, быстрый и отказоустойчивый Telegram-бот на **Go** для управления умным домом под управлением [Home Assistant](https://www.home-assistant.io/).

Позволяет в удобном интерактивном интерфейсе Telegram управлять устройствами, освещением, розетками, климатом, сценариями, просматривать показания датчиков и настраивать конфигурационные параметры умного дома.

---

## 🌟 Основные возможности

- 📁 **Управление по категориям (доменам)**:
  - 💡 **Освещение** (`light`) — переключение света с сохранением текущего состояния.
  - 🔌 **Розетки и реле** (`switch`) — управление реле, удлинителями и розетками.
  - 🌀 **Вентиляторы** (`fan`) и 💧 **Осушители / увлажнители** (`humidifier`).
  - ❄️ **Климат** (`climate`), 🪟 **Шторы и жалюзи** (`cover`), 🚿 **Водонагреватели** (`water_heater`).
  - 🚰 **Краны и клапаны** (`valve`), 🔒 **Замки** (`lock`), 🚨 **Сирены** (`siren`).
  - 📺 **Медиаплееры** (`media_player`), 🧹 **Пылесосы** (`vacuum`).
  - ⚡ **Автоматизации** (`automation`), 🎬 **Сцены** (`scene`), 📜 **Скрипты** (`script`), 🔘 **Переключатели** (`input_boolean`).
- 🏠 **Навигация по комнатам (Areas)**:
  - Просмотр всех устройств и датчиков, сгруппированных по комнатам вашего дома.
  - Мгновенное переключение устройств прямо из контекста комнаты.
- 🔀 **Интеллектуальная группировка многоканальных устройств (Multi-Gang / Relay Devices)**:
  - Устройства с несколькими управляемыми линиями (двухканальные выключатели, блоки розеток, модули реле) автоматически объединяются в единую удобную карточку устройства.
  - Индивидуальное управление каждым реле внутри карточки.
  - Автоматическая очистка избыточных префиксов в названиях каналов (кнопки остаются компактными и информативными).
  - Независимые датчики устройства (температура, влажность, энергопотребление) не схлопываются и доступны для прямого просмотра.
- ⚙️ **Тонкая конфигурация параметров (Entity Config)**:
  - Доступ к вспомогательным сущностям категорий `config` и `diagnostic`.
  - Выбор режимов работы (`select`, `input_select`).
  - Регулировка числовых параметров и лимитов (`number`, `input_number`).
  - Запуск сервисных кнопок (`button`, `input_button`).
- 📊 **Мониторинг сенсоров и датчиков**:
  - Быстрый просмотр показаний температуры, влажности, мощности, давления, батарей и статусов бинарных датчиков (открытие дверей, движение, протечки).
  - Форматирование чисел без избыточных дробных хвостов IEEE-754.
- 📱 **Продуманный UX в Telegram**:
  - Постоянное главное меню (Reply-кнопки внизу экрана) для быстрого доступа.
  - **Пагинация списков** (по 10 устройств на страницу) с защитой от лимитов Telegram API.
  - **Адаптивная сетка кнопок**: длинные названия выводятся на всю ширину экрана, короткие компактно группируются по 2 в ряд.
  - **Сжатие callback-данных**: автоматическое хэширование длинных идентификаторов (CRC32) для строгого соблюдения лимита Telegram `callback_data` (64 байта).
- ⚡ **Уведомление при запуске**:
  - Опциональная отправка сообщения при старте бота — полезно для фиксации момента включения электричества дома.
- 🛡️ **Безопасность**:
  - Доступ строго ограничен белым списком `ALLOWED_USER_ID`. Запросы от посторонних пользователей блокируются.

## 🏗 Архитектура и стек технологий

- **Язык**: Go (1.22+) — компиляция в единый статический бинарный файл без внешних зависимостей.
- **Потребление ресурсов**: ~15–25 МБ RAM в Docker-контейнере.
- **Интеграция с Home Assistant**:
  - **WebSocket API** (`config/entity_registry/list`, `config/device_registry/list`, `config/area_registry/list`) — получение актуального дерева комнат, устройств, категорий и скрытых сущностей.
  - **In-Memory кэширование** реестров HA с TTL 5 минут для максимальной скорости отклика.
  - **REST API** — мгновенный опрос текущих состояний (`/api/states`) и вызов сервисов (`/api/services/{domain}/{service}`).
- **Библиотеки**:
  - [`github.com/go-telegram-bot-api/telegram-bot-api/v5`](https://github.com/go-telegram-bot-api/telegram-bot-api) — работа с Telegram Bot API.
  - [`github.com/gorilla/websocket`](https://github.com/gorilla/websocket) — WebSocket-клиент к Home Assistant.
  - [`github.com/joho/godotenv`](https://github.com/joho/godotenv) — загрузка переменных окружения из `.env`.
- **Надежность**:
  - Индивидуальные таймауты: 5с для запросов к HA, 45с для Telegram Long Polling (защита от «зависших» TCP-сокетов).
  - Асинхронная обработка входящих обновлений в горутинах с изоляцией паник (`recover`).
  - Корректное завершение работы (Graceful Shutdown) по сигналам `SIGINT` / `SIGTERM`.

```
tg_bot_home_assistant/
├── bot/               # Логика Telegram-бота
│   ├── bot.go         # Инициализация, цикл опроса Long Polling, Graceful Shutdown
│   ├── handlers.go    # Обработчики команд, сообщений и callback-кнопок
│   └── keyboards.go   # Генерация инлайн-клавиатур, адаптивная сетка, пагинация, хэширование
├── config/            # Загрузка и валидация конфигурации из .env
│   └── config.go
├── ha/                # Клиент Home Assistant API
│   ├── client.go      # REST & WebSocket интеграция, кэширование реестров, вызов сервисов
│   └── types.go       # Модели сущностей, доменов, комнат и группировки
├── main.go            # Точка входа в приложение
├── Dockerfile         # Мультистейдж сборка легковесного контейнера Alpine
├── docker-compose.yml # Сервисный манипулятор запуска
└── .env.example       # Пример файла настроек окружения
```

## 📋 Предварительные требования

1. **Telegram-бот**:
   - Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте полученный **API Token**.
   - Узнайте свой Telegram ID через бота [@userinfobot](https://t.me/userinfobot) (параметр `Id`).
2. **Home Assistant**:
   - В интерфейсе Home Assistant откройте свой профиль (в левом нижнем углу).
   - В разделе **«Долгосрочные токены доступа»** (*Long-Lived Access Tokens*) создайте новый токен и скопируйте его.
   - Убедитесь, что Home Assistant доступен по локальной сети или доменному имени (например, `http://192.168.1.100:8123` или `http://homeassistant.local:8123`).

## ⚙️ Настройка конфигурации (`.env`)

Создайте файл `.env` на основе примера `.env.example`:

```bash
cp .env.example .env
```

Заполните обязательные параметры:

| Переменная | Обязательная | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `TELEGRAM_BOT_TOKEN` | **Да** | — | Токен вашего бота от `@BotFather` |
| `ALLOWED_USER_ID` | **Да** | — | Числовой ID вашего аккаунта Telegram для авторизации |
| `HA_URL` | **Да** | — | URL-адрес Home Assistant без слеша на конце (например, `http://192.168.1.100:8123`) |
| `HA_TOKEN` | **Да** | — | Долгоживущий токен доступа (Long-Lived Access Token) |
| `NOTIFY_ON_STARTUP` | Нет | `true` | Отправлять ли уведомление в Telegram при запуске бота |

Пример готового `.env`:

```env
TELEGRAM_BOT_TOKEN="1234567890:ABCDefGhIJKlmNoPQRsTUVwxyZ"
ALLOWED_USER_ID="987654321"
HA_URL="http://192.168.1.100:8123"
HA_TOKEN="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
NOTIFY_ON_STARTUP=true
```

## 🚀 Запуск

### Вариант 1: С помощью Docker Compose (Рекомендуемый)

Убедитесь, что установлены `docker` и `docker compose`.

1. **Соберите и запустите контейнер**:
   ```bash
   docker compose up -d --build
   ```

2. **Проверьте логи**:
   ```bash
   docker compose logs -f
   ```

3. **Остановка бота**:
   ```bash
   docker compose down
   ```

> [!TIP]
> Если Home Assistant и бот развернуты на одном Linux-сервере в локальной сети, в `docker-compose.yml` можно раскомментировать параметр `network_mode: host` для прямого сетевого доступа к сервисам хоста.

---

### Вариант 2: Локальный запуск (Go)

Требуется установленный Go версии 1.22+.

1. **Установите зависимости**:
   ```bash
   go mod download
   ```

2. **Запустите приложение**:
   ```bash
   go run main.go
   ```

3. **Сборка бинарного файла**:
   ```bash
   go build -o tg-bot main.go
   ./tg-bot
   ```

## 💬 Команды и управление ботом

### Команды в чате

| Команда | Описание |
| :--- | :--- |
| `/start` | Запуск бота, вывод приветствия и отображение главного меню |
| `/status` | Проверка связи с Home Assistant (версия HA, статус REST и WebSocket) |
| `/domains`, `/categories`, `/devices` | Меню категорий устройств (свет, розетки, климат и др.) |
| `/rooms`, `/areas` | Меню комнат вашего дома |
| `/config`, `/settings` | Меню конфигурационных сущностей и настроек |
| `/toggle <entity_id>` | Ручное переключение устройства по его `entity_id` (например, `/toggle switch.relay_1`) |

### Быстрые кнопки (Reply Keyboard)

- **📊 Статус HA** — состояние подключения, версия ядра Home Assistant и время отклика.
- **📁 Устройства по доменам** — интерактивный список категорий с фильтрацией пустых групп.
- **🏠 Устройства по комнатам** — выбор комнаты с просмотром всех привязанных устройств и датчиков.

## 🔒 Безопасность

- Бот строго проверяет ID отправителя каждого входящего сообщения и callback-запроса на соответствие значению `ALLOWED_USER_ID`.
- Запросы от неавторизованных пользователей не исполняются, а информация о попытке доступа логируется.
- Для вывода текстовых сообщений используется режим `HTML` с экранированием (`html.EscapeString`), что предотвращает инъекции разметки от нестандартных имен устройств.
